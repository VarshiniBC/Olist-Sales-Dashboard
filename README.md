# Olist E-Commerce Sales Dashboard

## Project Overview

An interactive Power BI dashboard built using the Brazilian Olist e-commerce dataset.

## Dashboard Features

- Total Sales
- Total Orders
- Total Customers
- Total Products
- Average Order Value
- Average Review Score
- Total Freight
- Monthly Orders Trend
- Monthly Sales Trend
- Sales by Product Category
- Sales by State
- Payment Method Distribution
- Orders by Status
- Average Review Score by Category
- Top 10 Sellers by Sales

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Olist Brazilian E-Commerce Dataset

## Dashboard

The dashboard provides interactive analysis using filters for:

- Year
- Month
- State
- Product Category
